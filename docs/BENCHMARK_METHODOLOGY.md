# Benchmark Methodology

ForgeXi uses paired evaluation. A comparison is valid only when both arms share the same task definition, repository/base revision, seed, execution budget, and declared model policy.

Raw trajectories are retained. Aggregate success metrics are derived only from valid pairs. Failed, timed-out, or missing runs remain visible and are never silently dropped. Unmeasured metrics are represented as null/unmeasured rather than estimated.

No file in benchmarks/results/ should be treated as evidence unless it was generated by the benchmark harness and identifies the ForgeXi commit and run manifest that produced it.
