# ForgeXi Submission Evidence Package

Status: development. This file intentionally contains no unmeasured performance claims.

## Required evidence before submission
- Working Nebius runtime using an eligible NVIDIA Nemotron model on the decision path.
- Reproducible benchmark manifest and paired baseline/ForgeXi runs.
- Machine-readable trajectory and scorecard artifacts.
- Test/build/security verification outputs.
- Measured latency and token usage; cost only when supported by provider evidence.
- Public working demo and public repository setup instructions.
- Demo video no longer than the competition limit.

## Evidence rule
A claim enters the submission only when a reproducible artifact identifies the task, code revision, runtime/model configuration, budget, commands, outputs, and verification result. Missing values remain explicitly unmeasured.
