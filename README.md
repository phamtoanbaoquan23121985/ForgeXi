# ForgeXi

Evidence-driven coding agent for the Nebius × NVIDIA Global AI Hackathon.

ForgeXi is being built around an inspectable engineering loop:

**Plan → Inspect → Act → Test → Diagnose → Repair → Verify → Evidence**

## Evidence policy

No benchmark, quality, latency, cost, or reliability claim is accepted without a reproducible run artifact. Measured results will be stored under `evidence/`.

## Status

Early development. The NVIDIA Nemotron / Nebius runtime integration and benchmark results are not yet claimed as complete.

## Development

Behavior changes follow test-driven development. Tests define the contracts before implementation.
